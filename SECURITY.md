# Security policy

## Supported versions

Only the latest minor release of the current major version gets security fixes.

| Version | Supported |
| ------- | --------- |
| 1.65.x  | Yes       |
| < 1.65  | No        |

## Report a vulnerability

Do not open a public issue.

Use GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/parisek/timber-kit/security) of the repository.
2. Select "Report a vulnerability".

You can also go straight to the [report form](https://github.com/parisek/timber-kit/security/advisories/new).

We aim to reply within 7 days.

## What to include

- The affected `parisek/timber-kit` version.
- Steps to reproduce the problem.
- The impact, as you understand it.

## What happens next

We confirm the problem and prepare a fix.
We ship the fix as a patch release.
We publish a GitHub Security Advisory with the release.
